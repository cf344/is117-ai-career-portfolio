## Compare possible portfolio designs

**Alternative A: Skills only.** List Python, data analysis and AI interests. Easy to make, but visitors cannot inspect how the skills were used.

**Alternative B: Evidence-based Projects section.** Link to real code and coursework, with a brief description of the question, tools, work and actual result. Harder to prepare, but stronger evidence.

**My choice:** Alternative B. I prefer showing actual work, not just listing abilities. This is a proposed design decision, not a tested result.
